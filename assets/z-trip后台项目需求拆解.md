## 一、系统概述

### 1.1 系统定位
Z-TRIP 后台管理系统是温州华夏航空服务有限公司的**客服协作与财务结算平台**，主要用于企业差旅服务（TMC）的订单处理、任务管理和财务结算工作。

### 1.2 系统入口
- **URL：** https://admin.z-trip.cn

### 1.3 系统架构
系统采用多模块化设计，主要分为三大功能板块：
1. 在线客服（任务处理中心）
2. 财务中心（结算管理平台）
3. 系统设置（账户管理）

## 二、功能模块详细分析

### 2.1 在线客服模块

#### 2.1.1 TMC服务台（核心任务中心）

**功能概述：**

| 1 | 国内机票 | 国内航班机票订单处理 |
| 2 | 国际机票 | 国际航班机票订单处理 |
| 3 | 酒店任务 | 国内酒店订单处理 |
| 4 | 酒店夜审 | 酒店夜间审核任务 |
| 5 | 鹰眼任务 | 特殊监控/预警任务 |
| 6 | 火车任务 | 火车票订单处理 |
| 7 | 保险任务 | 旅行保险订单处理 |
| 8 | 需求任务 | 客户特殊需求单处理 |
| 9 | 用车任务 | 用车服务订单处理 |
| 10 | 行程定制 | 定制化行程服务 |
| 11 | 企业协议 | 企业协议客户订单 |
| 12 | 企业直销 | 企业直销渠道订单 |

**任务状态分类：**

| 序号 | 状态类型 | 说明 |
|------|----------|------|
| 1 | 已关闭 | 任务领取状态（开关控制） |
| 2 | 我的任务 | 当前客服个人任务 |
| 3 | 全部任务 | 所有可查看任务 |
| 4 | 订单查询 | 按订单号精确查询 |
| 5 | 处理中 | 正在处理的任务 |
| 6 | 挂起中 | 暂停处理的任务 |
| 7 | 近期已处理 | 当日已处理任务统计 |
| 8 | 待出票 | 等待出票的任务 |
| 9 | 待催单 | 等待催促的任务 |
| 10 | 退审核 | 退款待审核任务 |
| 11 | 退复核 | 退款待复核任务 |
| 12 | 改签出票 | 改签待出票任务 |
| 13 | 改签审核 | 改签待审核任务 |

**信息维度标签页：**

| 序号 | 维度 | 说明 |

| 1 | 航班信息 | 航班相关详细信息 |

| 4 | 供应信息 | 供应商相关信息 |

**搜索功能：**
- 支持按**订单号**精确搜索
- 提供搜索和重置按钮

#### 2.1.2 客服任务手工维护

**功能概述：**  
提供手工创建和关闭任务的能力，用于处理系统自动分配之外的特殊任务。

**支持的任务类型：**

| 序号 | 类型 | 说明 |
|------|------|------|
| 1 | 国内机票 | - |
| 2 | 国际机票/国内机票（港澳台） | 包含港澳台地区 |
| 3 | 国内酒店 | - |
| 4 | 国际酒店 | - |
| 5 | 酒店夜审 | - |
| 6 | 火车 | 火车票任务 |
| 7 | 保险 | 保险订单任务 |
| 8 | 鹰眼 | 特殊监控任务 |
| 9 | 其他 | 其他类型任务 |

**任务处理方式：**

| 处理方式 | 可选任务类型 |
|----------|--------------|
| 创建任务 | 出票任务、改签任务、催单任务、退款任务、退复核任务 |
| 关闭任务 | 同上所有类型 |

**操作流程：**
1. 选择任务类型
2. 输入订单号
3. 选择处理方式（创建/关闭）
4. 选择具体任务类型
5. 执行或取消

#### 2.3.1 修改密码

**功能概述：**

**用户信息（只读）：**

| 序号 | 字段 | 示例值 |
|------|------|--------|
| 1 | 姓名 | 高雄 |
| 2 | 手机号码 | 19923575739 |
| 3 | 邮箱 | （未设置） |

**密码修改规则：**
- 新密码长度：至少8位
- 字符要求：必须同时包含

  - 字母

4. 点击确认修改

**安全提示：**

## 三、业务流程分析

### 3.1 客服任务处理流程

```
客户下单/需求 → 系统创建任务 → 任务分配 → 客服处理 → 出票/完成
                              ↓
                          异常情况 → 挂起/退审核/催单 → 继续处理
```

### 3.2 账单结算流程

```
消费发生 → 生成账单 → 发送企业 → 企业确认 → 开票 → 收款 → 结算完成
                     ↓
              逾期/争议 → 人工处理
```

### 3.3 结算账户管理流程

```
企业入驻 → 创建结算账户 → 设置结算规则 → 账户充值/授信 → 消费扣款 → 账单生成
```

## 四、数据关系分析

### 4.1 核心实体关系

```
企业账户 ←→ 账单 ←→ 消费订单
   ↓
结算规则
   ↓
授信额度/预存款
```

### 4.2 任务与订单关系

```
订单 → 任务 → 客服处理 → 状态更新
```

2. 账户停用需保留操作日志
