## 一、文档概述

### 1.1 文档目的

本文档为温州华夏航服B2B2C平台的产品需求文档，旨在：
- 明确各端功能需求、业务规则和验收标准
- 指导UI设计岗位进行原型和视觉设计
- 指导开发岗位进行代码实现
- 作为项目验收的依据

### 1.2 读者对象

- UI设计师：依据本文档进行原型设计和视觉设计
- 前端开发工程师：依据本文档进行页面开发
- 后端开发工程师：依据本文档进行接口开发和业务逻辑实现
- 测试工程师：依据本文档编写测试用例
- 项目经理：依据本文档进行项目管理和验收

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| PMC | Platform Management Center, SaaS平台管理端 |
| TMC | Team Management Center, 集团管理端 |
| MMC | Merchant Management Center, 商户端(子公司/分销商) |
| Corporate | 航司大客户，与航司签约的集团/组织 |
| GP | Government Personnel, 公务员大客户 |
| PNR | Passenger Name Record, 旅客订座记录 |
| 验价 | 出票前校验航司实时价格是否在可接受阈值内 |
| 外采 | TMC通过自签采购渠道直接采购，不经过PMC |
| 内采 | 通过PMC平台对接的上游采购渠道采购 |
| 分润 | 后返奖励，PMC从TMC/TMC从MMC的利润分成 |
| OA审批 | MMC内部办公审批模式，员工通过审批后公费出行 |
