## 一、审批流程系统

### 1.1 approval_flow - 审批流程定义表

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | BIGSERIAL | PK | 主键 |
| tenant_id | BIGINT | Y | 租户ID(0=全局) |
| flow_code | VARCHAR(64) | Y | 流程编码 如 WF202606140001 |
| flow_name | VARCHAR(128) | Y | 流程名称 |
| flow_type | VARCHAR(32) | Y | 流程类型: travel_approval=差旅审批, expense_approval=费用审批 |
| version | INT | Y | 流程版本，默认1 |
| status | SMALLINT | Y | 状态: 0=草稿, 1=已发布, 2=已停用 |
| description | TEXT | N | 流程描述 |
| created_by | BIGINT | N | 创建人 |
| published_at | TIMESTAMP | N | 发布时间 |
| created_at | TIMESTAMP | Y | 创建时间 |
| updated_at | TIMESTAMP | Y | 更新时间 |
| deleted_at | TIMESTAMP | N | 软删除时间 |

**唯一约束**: (tenant_id, flow_code, version)
