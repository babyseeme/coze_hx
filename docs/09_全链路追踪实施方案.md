# 全链路追踪实施方案

> 基于温州华夏航服B2B2C平台技术栈：Hyperf 3.1 + Swoole + MySQL + RabbitMQ + Vue3

---

## 一、全链路追踪ID机制设计

### 1.1 ID体系

```
trace_id     — 全链路追踪ID，贯穿一个完整业务链路（如：用户下单→支付→出票→通知）
span_id      — 当前调用跨度ID，标识链路中的单个节点
parent_span_id — 父跨度ID，构建调用树
```

**trace_id 生成规则**：`{timestamp_ms(13位)}-{tenant_id(6位)}-{随机数(4位)}`

示例：`1751097600000-000001-a3f2` → 可直接从trace_id读取时间戳和租户ID

### 1.2 链路传播路径

```
HTTP请求入口(C端/TMC/MMC/开放API)
  │ 生成 trace_id + root span_id
  │
  ├── Controller层 ──── 记录请求入参到 trace_log
  │     │
  │     ├── Service层 ── 生成子 span_id，parent=Controller的span
  │     │     │
  │     │     ├── Mapper层 ── SQL执行记录到 trace_log
  │     │     │
  │     │     ├── HTTP外部调用(航司接口) ── header携带trace_id
  │     │     │
  │     │     └── MQ消息投递 ── message携带trace_id + span_id
  │     │           │
  │     │           └── Consumer消费 ── 继承trace_id，生成新span_id
  │     │
  │     └── 事件分发(领域事件) ── event携带trace_id
  │
  └── 响应返回 ── 响应header携带trace_id
```

### 1.3 各入口trace_id生成规则

| 入口场景 | trace_id来源 | span_id |
|---------|-------------|---------|
| C端HTTP请求 | 网关生成 | `{trace_id}-0` (根节点) |
| PMC/TMC/MMC管理端 | 网关生成 | `{trace_id}-0` |
| 开放API调用 | 从请求header取，无则生成 | `{trace_id}-0` |
| MQ消费者 | 从消息体取 | `{trace_id}-{消费序号}` |
| 定时任务(cron) | 任务启动时生成 | `{trace_id}-0` |
| OA回调 | 从回调参数取/生成 | `{trace_id}-0` |
| DDL事件监听 | 从上下文取 | `{trace_id}-{事件序号}` |

## 二、Hyperf+Swoole 具体实现

### 2.1 核心中间件 — TraceMiddleware

```php
<?php
// app/System/Http/Middleware/TraceMiddleware.php

namespace App\System\Http\Middleware;

use Hyperf\Context\Context;
use Psr\Http\Message\ResponseInterface;
use Psr\Http\Message\ServerRequestInterface;
use Psr\Http\Server\MiddlewareInterface;
use Psr\Http\Server\RequestHandlerInterface;

class TraceMiddleware implements MiddlewareInterface
{
    public function process(ServerRequestInterface $request, RequestHandlerInterface $handler): ResponseInterface
    {
        // 1. 从请求header获取或生成trace_id
        $traceId = $request->getHeaderLine('X-Trace-Id')
            ?: $this->generateTraceId();

        // 2. 生成根span_id
        $spanId = $traceId . '-0';

        // 3. 存入Swoole协程上下文（非ThreadLocal，协程安全）
        Context::set('trace_id', $traceId);
        Context::set('span_id', $spanId);
        Context::set('trace_start_time', microtime(true));

        // 4. 记录请求入口日志
        $this->logRequest($request, $traceId, $spanId);

        // 5. 执行后续处理
        $response = $handler->handle($request);

        // 6. 响应header回传trace_id（方便前端/调用方排查）
        $response = $response->withHeader('X-Trace-Id', $traceId);

        // 7. 记录响应日志
        $this->logResponse($response, $traceId, $spanId);

        return $response;
    }

    private function generateTraceId(): string
    {
        $timestamp = (int)(microtime(true) * 1000);
        $tenantId = Context::get('tenant_id', 0);
        $random = random_int(1000, 9999);
        return sprintf('%d-%06d-%04d', $timestamp, $tenantId, $random);
    }

    private function logRequest($request, string $traceId, string $spanId): void
    {
        $log = [
            'trace_id'   => $traceId,
            'span_id'    => $spanId,
            'type'       => 'request_in',
            'method'     => $request->getMethod(),
            'uri'        => (string)$request->getUri(),
            'headers'    => $this->filterSensitiveHeaders($request->getHeaders()),
            'body'       => $this->truncateBody((string)$request->getBody()),
            'client_ip'  => $request->getHeaderLine('X-Real-IP') 
                            ?: $request->getServerParams()['remote_addr'] ?? '',
            'timestamp'  => date('Y-m-d H:i:s.v'),
        ];
        // 写入阿里云SLS（见第四节）
        $this->pushToLogQueue($log);
    }

    private function logResponse($response, string $traceId, string $spanId): void
    {
        $duration = round((microtime(true) - Context::get('trace_start_time')) * 1000, 2);
        $log = [
            'trace_id'    => $traceId,
            'span_id'     => $spanId,
            'type'        => 'response_out',
            'status_code' => $response->getStatusCode(),
            'duration_ms' => $duration,
            'timestamp'   => date('Y-m-d H:i:s.v'),
        ];
        $this->pushToLogQueue($log);
    }
}
```

### 2.2 上下文工具类 — TraceContext

```php
<?php
// app/Common/TraceContext.php

namespace App\Common;

use Hyperf\Context\Context;

class TraceContext
{
    /**
     * 获取当前trace_id
     */
    public static function getTraceId(): string
    {
        return Context::get('trace_id', '');
    }

    /**
     * 获取当前span_id
     */
    public static function getSpanId(): string
    {
        return Context::get('span_id', '');
    }

    /**
     * 生成子span_id（用于Service层调用、外部请求等）
     */
    public static function nextSpanId(): string
    {
        $currentSpan = self::getSpanId();
        $counter = Context::get('span_counter', 0) + 1;
        Context::set('span_counter', $counter);

        // 从当前span派生: parent-span → parent-span.1, parent-span.2
        $spanId = $currentSpan . '.' . $counter;
        Context::set('span_id', $spanId);
        return $spanId;
    }

    /**
     * 创建子上下文（用于MQ消费、异步任务等新协程场景）
     * 返回包含trace信息的数组，供新协程恢复上下文
     */
    public static function export(): array
    {
        return [
            'trace_id'     => Context::get('trace_id', ''),
            'span_id'      => Context::get('span_id', ''),
            'tenant_id'    => Context::get('tenant_id', 0),
        ];
    }

    /**
     * 在新协程中恢复trace上下文
     */
    public static function import(array $context): void
    {
        Context::set('trace_id', $context['trace_id'] ?? '');
        Context::set('span_id', $context['span_id'] ?? '');
        Context::set('tenant_id', $context['tenant_id'] ?? 0);
    }
}
```

### 2.3 Service层自动注入trace_id到数据库操作

```php
<?php
// app/Common/Model/TraceModelTrait.php

namespace App\Common\Model;

use App\Common\TraceContext;
use Hyperf\DbConnection\Db;

trait TraceModelTrait
{
    /**
     * 重写insert，自动注入trace_id
     */
    public static function insertTrace(array $data): bool
    {
        // 自动注入trace_id字段（如果表有此字段）
        if (!isset($data['trace_id'])) {
            $data['trace_id'] = TraceContext::getTraceId();
        }
        return Db::table((new static)->getTable())->insert($data);
    }

    /**
     * 重写update，同时记录变更日志
     */
    public static function updateWithTrace($id, array $data): int
    {
        if (!isset($data['trace_id'])) {
            $data['trace_id'] = TraceContext::getTraceId();
        }
        return Db::table((new static)->getTable())
            ->where('id', $id)
            ->update($data);
    }
}
```

### 2.4 MQ消息trace_id传递

```php
<?php
// 生产者 — 发送MQ消息时携带trace上下文

namespace App\Common\MQ;

use App\Common\TraceContext;
use Hyperf\Amqp\Producer;
use Hyperf\Amqp\Message\Message;

class TraceProducer
{
    public function send(Message $message): bool
    {
        // 将trace上下文注入消息header
        $context = TraceContext::export();
        $message->setApplicationData(json_encode([
            'trace_context' => $context,
        ]));

        return di(Producer::class)->produce($message);
    }
}


// 消费者 — 消费MQ消息时恢复trace上下文

namespace App\Common\MQ;

use App\Common\TraceContext;
use Hyperf\Amqp\Result;
use Hyperf\Amqp\Message\ConsumerMessage;

abstract class TraceConsumer extends ConsumerMessage
{
    public function consumeMessage($data, \PhpAmqpLib\Message\AMQPMessage $message): Result
    {
        // 从消息header恢复trace上下文
        $appData = json_decode($message->get('application_headers')->getNativeData()['application_data'] ?? '{}', true);
        if (isset($appData['trace_context'])) {
            TraceContext::import($appData['trace_context']);
            // 生成新的消费span
            TraceContext::nextSpanId();
        }

        try {
            $result = $this->handle($data);
            $this->logConsume($data, 'success');
            return $result;
        } catch (\Throwable $e) {
            $this->logConsume($data, 'failed', $e);
            return Result::REQUEUE;
        }
    }

    abstract protected function handle($data): Result;
}
```

### 2.5 外部HTTP调用trace_id传递（航司接口等）

```php
<?php
// app/Common/Http/TraceHttpClient.php

namespace App\Common\Http;

use App\Common\TraceContext;
use Hyperf\Guzzle\ClientFactory;
use GuzzleHttp\Client;

class TraceHttpClient
{
    private Client $client;

    public function __construct(ClientFactory $factory)
    {
        $this->client = $factory->create([
            'timeout' => 30,
        ]);
    }

    public function request(string $method, string $uri, array $options = [])
    {
        // 注入trace_id到请求header
        $headers = $options['headers'] ?? [];
        $headers['X-Trace-Id'] = TraceContext::getTraceId();
        $headers['X-Span-Id'] = TraceContext::nextSpanId();
        $options['headers'] = $headers;

        $startTime = microtime(true);

        try {
            $response = $this->client->request($method, $uri, $options);
            $duration = round((microtime(true) - $startTime) * 1000, 2);

            // 记录外部调用日志
            $this->logExternalCall($method, $uri, $duration, $response->getStatusCode(), null);

            return $response;
        } catch (\Throwable $e) {
            $duration = round((microtime(true) - $startTime) * 1000, 2);
            $this->logExternalCall($method, $uri, $duration, 0, $e->getMessage());
            throw $e;
        }
    }
}
```

### 4.2 方案选择

| 方案 | 延迟 | 可靠性 | 适用场景 |
|------|------|--------|---------|
| **A. Logtail采集日志文件** | 秒级 | 高(文件缓冲) | 生产环境首选 |
| B. SDK直写SLS API | 毫秒级 | 中(网络异常丢日志) | 开发/测试环境 |

```php
// app/Common/Logger/TraceJsonFormatter.php

namespace App\Common\Logger;

use App\Common\TraceContext;
use Monolog\Formatter\JsonFormatter;
use Monolog\LogRecord;

class TraceJsonFormatter extends JsonFormatter
{
    public function format(LogRecord $record): string
    {
        // 注入trace上下文到每条日志
        $record = $record->with([
            'extra' => array_merge($record->extra, [
                'trace_id'        => TraceContext::getTraceId(),
                'span_id'         => TraceContext::getSpanId(),
                'tenant_id'       => \Hyperf\Context\Context::get('tenant_id', 0),
                'request_id'      => \Hyperf\Context\Context::get('request_id', ''),
            ]),
        ]);

        // 标准化输出格式（SLS友好）
        $normalized = [
            'timestamp'   => $record->datetime->format('Y-m-d\TH:i:s.vP'),
            'level'       => $record->level->name,
            'trace_id'    => $record->extra['trace_id'] ?? '',
            'span_id'     => $record->extra['span_id'] ?? '',
            'tenant_id'   => $record->extra['tenant_id'] ?? 0,
            'channel'     => $record->channel,
            'message'     => $record->message,
            'context'     => $record->context,
        ];

        return $this->toJson($normalized, true) . "\n";
    }
}
```

### 4.4 SDK直写方案（关键日志实时写入）

```php
<?php
// app/Common/Logger/SlsLogger.php

namespace App\Common\Logger;

use AlibabaCloud\SDK\Sls\V20201230\Sls;
use AlibabaCloud\SDK\Sls\V20201230\Models\PutLogsRequest;
use App\Common\TraceContext;
use Hyperf\Coroutine\Parallel;

class SlsLogger
{
    private Sls $client;
    private string $project;
    private string $logstore;
    private string $endpoint;

    public function __construct()
    {
        $this->endpoint = env('SLS_ENDPOINT', 'cn-hangzhou.log.aliyuncs.com');
        $this->project = env('SLS_PROJECT', 'hx-b2b2c-prod');
        $this->client = new Sls([
            'accessKeyId'     => env('SLS_ACCESS_KEY_ID'),
            'accessKeySecret' => env('SLS_ACCESS_KEY_SECRET'),
            'endpoint'        => $this->endpoint,
        ]);
    }

    /**
     * 写入日志到SLS（异步协程，不阻塞主流程）
     */
    public function log(string $logstore, string $level, string $message, array $context = []): void
    {
        // 协程异步写入，不影响主流程性能
        parallel(function () use ($logstore, $level, $message, $context) {
            try {
                $logItem = [
                    'timestamp'  => time(),
                    'level'      => $level,
                    'trace_id'   => TraceContext::getTraceId(),
                    'span_id'    => TraceContext::getSpanId(),
                    'tenant_id'  => \Hyperf\Context\Context::get('tenant_id', 0),
                    'message'    => $message,
                    'context'    => json_encode($context, JSON_UNESCAPED_UNICODE),
                    'host'       => gethostname(),
                    'service'    => 'hyperf-main',
                ];

                $this->client->putLogs(new PutLogsRequest([
                    'project'   => $this->project,
                    'logstore'  => $logstore,
                    'logItems'  => [$logItem],
                    'topic'     => $context['topic'] ?? 'default',
                    'source'    => gethostname(),
                ]));
            } catch (\Throwable $e) {
                // SLS写入失败不影响业务，仅本地记录
                logger()->warning('SLS日志写入失败: ' . $e->getMessage());
            }
        });
    }

    /**
     * 批量写入（减少API调用次数）
     */
    public function batchLog(string $logstore, array $logs): void
    {
        parallel(function () use ($logstore, $logs) {
            try {
                $logItems = array_map(function ($log) {
                    return array_merge($log, [
                        'trace_id'  => $log['trace_id'] ?? TraceContext::getTraceId(),
                        'span_id'   => $log['span_id'] ?? TraceContext::getSpanId(),
                        'timestamp' => $log['timestamp'] ?? time(),
                    ]);
                }, $logs);

                // SLS单次最多写入4096条
                foreach (array_chunk($logItems, 4096) as $chunk) {
                    $this->client->putLogs(new PutLogsRequest([
                        'project'  => $this->project,
                        'logstore' => $logstore,
                        'logItems' => $chunk,
                        'topic'    => 'batch',
                        'source'   => gethostname(),
                    ]));
                }
            } catch (\Throwable $e) {
                logger()->warning('SLS批量日志写入失败: ' . $e->getMessage());
            }
        });
    }
}
```

```php
namespace App\Common\Logger;

use App\Common\TraceContext;

class BusinessLogger
{
    private SlsLogger $slsLogger;

    public function __construct(SlsLogger $slsLogger)
    {
        $this->slsLogger = $slsLogger;
    }

    // ============ 订单链路 ============

    public function orderCreated(int $orderId, string $orderNo, array $detail): void
    {
        $this->slsLogger->log('trace-business', 'INFO', '订单创建', [
            'topic'    => 'order',
            'action'   => 'created',
            'order_id' => $orderId,
            'order_no' => $orderNo,
            'detail'   => $detail,
        ]);
    }

    public function orderPaid(int $orderId, float $amount, string $payMethod): void
    {
        $this->slsLogger->log('trace-business', 'INFO', '订单支付成功', [
            'topic'      => 'order',
            'action'     => 'paid',
            'order_id'   => $orderId,
            'amount'     => $amount,
            'pay_method' => $payMethod,
        ]);
    }

    public function ticketIssued(int $orderId, string $pnr, string $ticketNo): void
    {
        $this->slsLogger->log('trace-business', 'INFO', '出票成功', [
            'topic'     => 'ticket',
            'action'    => 'issued',
            'order_id'  => $orderId,
            'pnr'       => $pnr,
            'ticket_no' => $ticketNo,
        ]);
    }

    public function ticketFailed(int $orderId, string $reason, array $request = []): void
    {
        $this->slsLogger->log('trace-business', 'ERROR', '出票失败', [
            'topic'    => 'ticket',
            'action'   => 'failed',
            'order_id' => $orderId,
            'reason'   => $reason,
            'request'  => $request,
        ]);
    }

    // ============ 采购链路 ============

    public function procurementRequest(int $orderId, string $channel, array $params): void
    {
        $this->slsLogger->log('trace-business', 'INFO', '发起采购请求', [
            'topic'    => 'procurement',
            'action'   => 'request',
            'order_id' => $orderId,
            'channel'  => $channel,
            'params'   => $params,
        ]);
    }

    public function procurementResponse(int $orderId, string $channel, array $response, float $duration): void
    {
        $this->slsLogger->log('trace-business', $response['success'] ? 'INFO' : 'WARN', '采购响应', [
            'topic'     => 'procurement',
            'action'    => 'response',
            'order_id'  => $orderId,
            'channel'   => $channel,
            'success'   => $response['success'] ?? false,
            'duration'  => $duration,
            'response'  => $response,
        ]);
    }

    // ============ 退款链路 ============

    public function refundRequested(int $orderId, float $amount, string $reason): void
    {
        $this->slsLogger->log('trace-business', 'INFO', '退款申请', [
            'topic'    => 'refund',
            'action'   => 'requested',
            'order_id' => $orderId,
            'amount'   => $amount,
            'reason'   => $reason,
        ]);
    }

    // ============ 外部调用 ============

    public function externalCall(string $service, string $method, string $uri, float $duration, int $statusCode, ?string $error = null): void
    {
        $this->slsLogger->log('trace-external', $error ? 'ERROR' : 'INFO', '外部API调用', [
            'topic'       => 'external',
            'service'     => $service,
            'method'      => $method,
            'uri'         => $uri,
            'duration_ms' => $duration,
            'status_code' => $statusCode,
            'error'       => $error,
        ]);
    }

    // ============ 慢SQL ============

    public function slowSql(string $sql, float $duration, string $table = ''): void
    {
        $this->slsLogger->log('trace-sql', 'WARN', '慢SQL', [
            'topic'       => 'slow_sql',
            'sql'         => $this->truncateSql($sql),
            'duration_ms' => $duration,
            'table'       => $table,
        ]);
    }
}
```

### 4.6 SLS查询与Trace分析

#### SLS查询语法

```sql
-- 1. 按trace_id查询全链路
trace_id: "1751097600000-000001-a3f2"

-- 2. 按订单号查询（需在日志context中包含order_no）
* and order_no: "ORD20260628001"

-- 3. 查询出票失败的所有链路
* and topic: "ticket" and action: "failed"

-- 4. 查询某个租户的所有错误
* and tenant_id: 1 and level: ERROR

-- 5. 查询慢于2秒的外部API调用
* and topic: "external" and duration_ms > 2000

-- 6. 查询特定时间段的链路耗时分布
* | SELECT trace_id, 
    max_by(duration_ms, span_id) as max_duration,
    count(*) as span_count
  GROUP BY trace_id 
  ORDER BY max_duration DESC 
  LIMIT 20
```

### 5.2 运维查询脚本

```sql
-- ========================================
-- 运维常用: 按trace_id查全链路数据
-- 用法: 替换 @trace_id 变量值
-- ========================================

SET @trace_id = '1751097600000-000001-a3f2';

-- 订单主表
SELECT 'order' AS tbl, id, order_no, status, total_amount, created_at
FROM `order` WHERE trace_id = @trace_id;

-- 机票子单
SELECT 'order_item_flight' AS tbl, id, order_id, pnr, ticket_no, status, created_at

SELECT 'payment_log' AS tbl, id, order_id, pay_method, amount, status, created_at
FROM `payment_log` WHERE trace_id = @trace_id;

-- 退款记录
SELECT 'finance_refund' AS tbl, id, order_id, refund_amount, refund_status, created_at

-- 审批记录
SELECT 'approval_record' AS tbl, id, instance_id, action, operator_name, created_at

-- 通知记录
SELECT 'notify_inbox' AS tbl, id, user_id, title, is_read, created_at

-- 队列任务
SELECT 'queue_task' AS tbl, id, task_type, status, retry_count, created_at

SELECT 'c_member_balance_log' AS tbl, id, user_id, change_amount, before_balance, after_balance, created_at
```

### 5.3 queue_task 表的版本快照用法

```sql
-- queue_task 表结构中 snapshot_version 字段的使用:

-- 1. 查看某个trace_id下的所有异步任务
SELECT id, task_type, payload_snapshot, snapshot_version, status, retry_count, 
       error_message, created_at, started_at, completed_at
FROM `queue_task`
WHERE trace_id = '1751097600000-000001-a3f2'
ORDER BY created_at;

-- 2. 查看失败任务的业务数据快照（用于排查失败原因）
SELECT id, task_type, 
       JSON_EXTRACT(payload_snapshot, '$.order_id') AS order_id,
       JSON_EXTRACT(payload_snapshot, '$.flight_info.departure') AS departure,
       JSON_EXTRACT(payload_snapshot, '$.procurement_channel') AS channel,
       snapshot_version, error_message
FROM `queue_task`
WHERE trace_id = '1751097600000-000001-a3f2'
  AND status = 'failed';

-- 3. 重试失败任务（手动修复后）
UPDATE `queue_task`
SET status = 'pending', retry_count = retry_count + 1, error_message = NULL
WHERE trace_id = '1751097600000-000001-a3f2'
  AND status = 'failed'
  AND retry_count < max_retries;
```

### 6.2 前端全局拦截（Vue3）

```typescript
// web/src/utils/trace.ts

import axios from 'axios'

// 响应拦截器 — 自动捕获trace_id
axios.interceptors.response.use(
  (response) => {
    const traceId = response.headers['x-trace-id']
    if (traceId) {
      // 存入全局状态，方便开发面板查看
      window.__TRACE_ID__ = traceId
      console.log(`[Trace] ${traceId}`, response.config.url)
    }
    return response
  },
  (error) => {
    const traceId = error.response?.headers['x-trace-id']
    if (traceId) {
      // 错误时自动弹窗显示trace_id，方便用户反馈
      console.error(`[Trace Error] trace_id: ${traceId}`)
      // 提示用户: "出错啦，请将以下编号反馈给客服: ${traceId}"
    }
    return Promise.reject(error)
  }
)
```

## 七、成本估算与优化

### 7.1 SLS日志量估算

| 日志类型 | 日均量 | 单条大小 | 日均存储 |
|---------|--------|---------|---------|
| trace-access | 50万条 | 0.5KB | 250MB |
| trace-business | 20万条 | 0.8KB | 160MB |
| trace-sql | 5万条 | 0.3KB | 15MB |
| trace-external | 10万条 | 0.6KB | 60MB |
| trace-mq | 15万条 | 0.4KB | 60MB |
| **合计** | **100万条** | — | **545MB/天 ≈ 16GB/月** |

### 7.2 成本优化策略

| 策略 | 说明 |
|------|------|
| 热冷分层 | 热数据(7天)SSD，冷数据(30天)OSS，归档(>30天)OSS低频 |
| 日志采样 | 正常请求采样10%，错误/慢请求100%采集 |
| 聚合写入 | 批量提交(log batch)，减少API调用次数 |
| 字段裁剪 | 敏感字段脱敏，大字段截断(如response body >1KB截断) |
| 按租户隔离 | 各TMC租户日志独立logstore，避免互相影响 |
