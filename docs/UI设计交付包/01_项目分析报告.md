## 一、产品概述

### 1.1 产品是什么

华夏航服是一个 **B2B2C航空旅游综合服务平台**，连接航司/酒店等供应商 → TMC集团 → MMC商户 → C端消费者，提供机票、火车票、酒店预订和积分商城服务。

### 1.2 产品定位

| 维度 | 说明 |
|------|------|
| 行业 | 航空旅游 / 商旅管理 |
| 模式 | B2B2C（平台→商户→消费者） |
| 核心价值 | 一站式航旅采购+差旅管理+会员运营 |
| 竞品参考 | 携程商旅、同程商旅、飞猪企业版 |

### 1.3 设计范围（4端+1小程序）

| 端 | 类型 | 设计重点 | 响应式 |
|---|------|---------|--------|
| **PMC平台管理端** | Web后台 | 数据密集、表单复杂、专业感 | 1920px主，1440px兼容 |
| **TMC集团管理端** | Web后台 | 经营管理、配置型页面 | 1920px主，1440px兼容 |
| **MMC商户管理端** | Web后台 | 出票操作、审批、装修 | 1920px主，1440px兼容 |
| **C端(Web)** | 响应式网站 | 机票/酒店搜索、下单、会员 | 1440/768/375 |
| **C端(小程序)** | 微信小程序 | 核心预订+会员+商城 | 375px(750rpx) |

**注意**: 每个MMC商户可拥有独立微信小程序（不同AppID、不同品牌皮肤），需设计DIY装修能力。

### 2.2 核心用户画像

#### 画像1：PMC超级管理员（陈总 42岁）

```
角色: 平台方最高管理者
频率: 每日1-2小时
场景: 审批TMC入驻申请、监控平台经营数据、处理重大异常
痛点: 需要全局视角，一屏看懂平台运营健康度
设计关注: 大屏看板、关键指标醒目、异常高亮告警
```

#### 画像2：TMC财务主管（王姐 38岁）

```
角色: 集团结算与分润管理者
频率: 每日3-4小时
场景: 月结账单生成、信用额度审批、分润对账、供应商结算
痛点: 数据量大，对账操作繁琐，需要快速定位差异项
设计关注: 表格数据高效展示、批量操作、差异项醒目标记
```

#### 画像3：MMC出票专员（小李 26岁）

```
角色: 日常机票出票操作者
频率: 每日6-8小时
场景: 处理待出票队列、验价出票、处理航变通知、退改签操作
痛点: 高频操作，需要极速响应；航变时需批量处理
设计关注: 列表操作效率、快捷键支持、批量操作、实时状态刷新
```

#### 画像4：C端企业员工（张明 30岁）

```
角色: MMC子公司员工，需OA审批差旅
频率: 每月2-3次
场景: 提交差旅审批→审批通过→预订机票/酒店→出行→报销
痛点: 审批流程不透明，不知道卡在哪一步
设计关注: 审批进度可视化、一键催办、消息通知
```

#### 画像5：C端普通消费者（刘姐 45岁）

```
角色: 通过MMC分销商小程序购票的普通用户
频率: 每季度1-2次
场景: 搜索机票→比价→下单支付→查看行程→退改签
痛点: 机票价格术语看不懂，退改规则复杂
设计关注: 信息简化、价格透明、退改规则直观展示
```

## 四、关键交互模式

### 4.1 机票搜索交互（C端核心路径）

```
用户操作流程:
首页 → 选择"机票" → 输入出发/到达/日期 → 搜索 → 筛选/排序 → 选择航班 → 
查看详情 → 添加乘机人 → 确认订单 → 选择支付方式(在线/审批) → 支付/提交审批

交互要点:
- 出发到达城市支持拼音/三字码搜索
- 日期选择器标注低价日历
- 搜索结果支持: 按价格/时间/航司筛选
- 航班卡片: 航司Logo+航班号+起降时间+经停+舱位价格
- 订单确认页: 行程摘要+乘机人+保险+退改规则+费用明细
```

### 4.2 OA审批交互（MMC内部员工场景）

```
三种审批模式:
模式1: MMC端创建审批单 → 审批通过 → MMC端直接下单
模式2: C端选"差旅审批" → 审批通过 → 自动下单
模式3: C端先在线支付 → 7日内提交审批 → 审批通过 → 原路退款

交互要点:
- 审批进度条: 可视化显示当前节点+审批人
- 审批详情: 行程信息+费用预估+历史审批记录
- 审批操作: 同意/拒绝/转交/加签
- 消息通知: 审批待办/审批结果(微信+站内信)
```

### 4.3 出票中心交互（MMC出票员高频操作）

```
操作流程:
待出票列表 → 选择订单 → 验价 → 确认出票 → 等待航司响应 → 出票成功/失败

交互要点:
- 列表: 实时刷新、订单倒计时(座位保留时效)
- 验价: 价格波动提示(缓存价 vs 实时价差异高亮)
- 批量出票: 勾选多笔订单一键出票
- 航变通知: 弹窗+声音提醒，批量处理改签/退票
- 出票失败: 降级方案提示(联系客户/改签/退票)
```

### 4.4 月结对账交互（TMC/PMC财务场景）

```
操作流程:
选择账期 → 生成账单 → 明细核对 → 差异标记 → 确认对账 → 付款/收款

交互要点:
- 账单概览: 应收/应付/差额一目了然
- 明细表: 支持筛选/搜索/导出
- 差异项: 红色高亮，支持添加备注
- 批量确认: 勾选正常项一键确认
- 审批流: 财务主管确认 → 总经理审批
```

### 4.5 小程序DIY装修交互（MMC运营场景）

```
操作流程:
选择页面 → 从组件库拖入画布 → 配置组件参数 → 预览 → 发布

交互要点:
- 左侧: 组件库(分类列表)
- 中间: 手机预览画布(375px)
- 右侧: 组件参数配置面板
- 支持拖拽排序、删除、复制
- 实时预览(模拟器)
- 发布前对比(新旧版本)
```

## 五、设计规范建议

### 5.1 色彩方向

| 端 | 主色方向 | 理由 |
|---|---------|------|
| PMC | 深蓝/墨蓝 | 专业、权威、管控感 |
| TMC | 靛蓝/钢蓝 | 商务、信任、稳重 |
| MMC | 天蓝/亮蓝 | 效率、清晰、操作感 |
| C端Web | 品牌主色(可由MMC配置) | 个性化、亲切 |
| 小程序 | 品牌主色(DIY配置) | 每个MMC独立品牌 |

### 5.2 通用设计Token

| Token | 建议值 |
|-------|--------|
| 圆角 | 4px(后台) / 8px(C端) / 12px(卡片) |
| 阴影 | 0 2px 8px rgba(0,0,0,0.08) |
| 字号 | 12/13/14/16/20/24/28 |
| 行高 | 1.5 |
| 间距基准 | 4px |
| 动效时长 | 200ms(微交互) / 300ms(页面切换) |

### 5.3 核心组件清单

| 组件 | 使用场景 | 规格说明 |
|------|---------|---------|
| 搜索框 | 机票/酒店搜索 | 支持城市选择器+日期选择器联动 |
