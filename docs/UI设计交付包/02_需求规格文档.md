## 二、核心页面交互规格

### 2.1 机票搜索与预订（C端核心路径）

#### 搜索交互

| 步骤 | 交互 | 规则 |
|------|------|------|
| 选择出发城市 | 点击输入框→弹出城市选择器 | 支持热门/拼音/三字码搜索，默认定位当前城市 |
| 选择到达城市 | 同上 | 搜索结果排除出发城市，点击可交换出发/到达 |
| 选择日期 | 点击日期→弹出日历 | 默认今天，高亮低价日，支持多日历(往返) |
| 单程/往返 | Tab切换 | 切换时动画过渡，往返增加返程日期 |
| 搜索 | 点击搜索按钮 | Loading → 结果页，无结果展示空状态+推荐 |

## 四、通用组件规范

### 4.1 状态标签色值

| 状态类型 | 色值 | 场景 |
|---------|------|------|
| 待处理 | `#FA8C16`(橙) | 待支付/待出票/待审核 |
| 进行中 | `#1890FF`(蓝) | 出票中/审批中/处理中 |
| 成功 | `#52C41A`(绿) | 已出票/审批通过/已完成 |
| 失败 | `#F5222D`(红) | 出票失败/审批拒绝/已取消 |
| 警告 | `#FAAD14`(黄) | 航变/价格波动/即将超时 |
| 中性 | `#8C8C8C`(灰) | 已退票/已关闭 |

### 4.2 后台表格规范

| 元素 | 规格 |
|------|------|
| 表头 | 背景#FAFAFA，字重600，字号13px |
| 行高 | 54px(含padding) |
| 斑马纹 | 奇数行#FFF，偶数行#FAFAFA |
| 操作列 | 文字按钮，主操作蓝色，危险操作红色 |
| 批量操作 | 表格上方，选中N项后显示 |
| 空状态 | 插画+文案+操作按钮 |

### 4.3 表单规范

| 元素 | 规格 |
|------|------|
| 标签 | 右对齐，宽度80/120px，字号14px |
| 输入框 | 高度32px，圆角4px |
| 必填标记 | 红色*号在标签前 |
| 校验 | 失焦校验+提交校验，错误信息红色显示在字段下方 |
| 分组 | Card卡片分组，标题字重600 |
| 按钮 | 主按钮(实心蓝) / 次按钮(白底蓝边) / 文字按钮(无边框) |

### 4.4 弹窗规范

| 类型 | 规格 |
|------|------|
| 确认弹窗 | 宽420px，标题+内容+双按钮 |
| 表单弹窗 | 宽600/800px，可滚动 |
| 详情抽屉 | 右侧滑出，宽640px |
| 全屏弹窗 | 用于复杂表单/预览 |

### 4.5 数据卡片(仪表盘)规范

```
┌──────────────────┐
│  今日出票量        │ ← 标题 14px #666

│  └──────────────┘│
```
