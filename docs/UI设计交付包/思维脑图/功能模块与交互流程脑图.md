## 二、交互流程脑图

```
核心交互流程
│
├── 机票预订流程(C端)
│   ├── 搜索 → 选航班 → 选舱位 → 填乘机人 → 确认订单
│   │   ├── 在线支付 → 支付成功 → 待出票 → 已出票
│   │   └── 差旅审批 → 审批中 → 通过→自动下单 / 拒绝→关闭
│   │
│   └── 先付后审(7日内)
│       └── 已支付订单 → 提交审批 → 审批通过 → 原路退款
│
├── 出票流程(MMC端)
│   ├── 自动出票: 支付成功 → 自动验价 → 阈值内出票 → 成功/失败
│   └── 手动出票: 待出票列表 → 验价 → 确认出票 → 等待响应 → 成功/失败
│       └── 失败降级: 联系客户 → 改签/退票
│
├── 采购流程(TMC端)
│   ├── 内采: MMC→TMC→PMC→航司接口
│   └── 外采: MMC→TMC→导出订单→人工出票→导入核销
│
├── 退改签流程(C端→MMC)
│   ├── 退票: 申请→审核→提交航司→航司确认→退款
│   ├── 改签: 申请→审核→查询可改航班→确认改签→出票
│   └── 航变: 系统推送→MMC处理→通知C端→改签/退票
│
├── 结算流程(TMC/PMC)
│   ├── 实时结算: C端支付→MMC→TMC(实时分账)
│   ├── 月结结算: 月末生成账单→核对→确认→付款
│   └── 信用额度: 授信→消费→还款/扣款
│
├── 审批流程(对接OA)
│   ├── 创建审批单→提交OA→OA审批→回调通知→下单/退款
│   └── OA支持: 钉钉/飞书/企业微信
│
├── 会员体系流程
│   ├── 注册→完善信息→等级初始化
│   ├── 消费→积分累积→等级升级
│   ├── 签到→积分奖励→连续签到加成
│   └── 积分使用→商城兑换/抵扣
│
└── 小程序装修流程(MMC)
    ├── 选择页面→拖入组件→配置参数→预览→发布
    └── 组件: 轮播图/导航/搜索框/商品/广告/公告/富文本
```
