## 三、开发规范

### 3.1 命名规范

| 类型 | 规范 | 示例 |
|------|------|------|
| Controller | PascalCase + Controller | `FlightController.php` |
| Service | PascalCase + Service | `FlightSearchService.php` |
| Mapper | PascalCase + Mapper | `FlightMapper.php` |
| Model | PascalCase(与表名对应) | `OrderItemFlight.php` |
| Schema | PascalCase + Schema | `FlightSearchSchema.php` |
| 方法名 | camelCase | `searchFlights()` |
| 数据库表 | snake_case + 前缀 | `order_item_flight` |
| 数据库字段 | snake_case | `trace_id` |
| API路由 | kebab-case | `/api/v1/flight/search` |
| 常量 | UPPER_SNAKE_CASE | `ORDER_STATUS_PAID` |

### 3.2 接口规范

```
RESTful API 规范:
GET    /api/v1/orders          # 列表
GET    /api/v1/orders/{id}     # 详情
POST   /api/v1/orders          # 创建
PUT    /api/v1/orders/{id}     # 更新
DELETE /api/v1/orders/{id}     # 删除

响应格式:
{
    "code": 200,
    "message": "success",
    "data": { ... },
    "trace_id": "tmc01_20260628_abc123def"   # 全链路追踪ID
}

分页格式:
{
    "code": 200,
    "data": {
        "list": [...],
        "pagination": {
            "page": 1,
            "page_size": 20,
            "total": 100
        }
    }
}

错误响应:
{
    "code": 40001,
    "message": "余额不足",
    "data": null,
    "trace_id": "tmc01_20260628_abc123def"
}
```

### 3.4 全链路追踪

详见: `09_全链路追踪实施方案.md`

**核心规则**:
1. HTTP入口: `TraceMiddleware` 自动生成 trace_id
2. 服务调用: 通过 `TraceContext::getTraceId()` 传递
3. MQ消息: header中携带 trace_id
4. 数据库写入: ModelTrait 自动填充 trace_id
5. 外部API: HTTP Client 自动传播 trace_id
6. 日志输出: 每行日志携带 trace_id

### 3.5 异步队列规范

```php
// 队列定义 (config/autoload/queue.php)
return [
    'ticket_issue'   => ['exchange' => 'order', 'routing_key' => 'ticket.issue'],
    'refund_process' => ['exchange' => 'order', 'routing_key' => 'refund.process'],
    'notify_send'    => ['exchange' => 'notify', 'routing_key' => 'notify.send'],
    'import_task'    => ['exchange' => 'system', 'routing_key' => 'system.import'],
    'bill_generate'  => ['exchange' => 'finance', 'routing_key' => 'finance.bill'],
];

// 投递消息 (必须携带 trace_id)
QueueService::push('ticket_issue', [
    'order_id' => $orderId,
    'trace_context' => TraceContext::toArray(),
], [
    'version' => 'v1',  // 队列任务版本
]);

// 消费消息 (恢复 trace_id)
class TicketIssueConsumer implements ConsumerInterface {
    public function consume(Message $message): string {
        $payload = json_decode($message->getBody(), true);
        TraceContext::fromArray($payload['trace_context']);
        // ... 业务逻辑
    }
}
```

### 3.6 领域事件

```php
// 事件定义
class OrderPaidEvent extends Event {
    public int $orderId;
    public string $traceId;
    public float $amount;
}

// 事件触发
Event::dispatch(new OrderPaidEvent($orderId, $traceId, $amount));

// 事件监听(当前同步, 后续可切异步)
class OrderPaidListener implements ListenerInterface {
    public function listen(): array {

    }
}
```
